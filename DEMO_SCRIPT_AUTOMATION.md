# Automation Demo Script (Pilot Narrative)

## Scenario arc
1. Start with a healthy low-risk package.
2. Show blocked risky package import due to missing entitlement.
3. Run setup wizard and resolve blockers.
4. Mark readiness and show first-value milestones.
5. Show underperforming case in success/ROI and intervention note.
6. Show governance conflict visibility and remediation.

## Demo path
- `/ops` → `/ops/automation-library`
- `/ops/automation-setup`
- `/ops/automation-success`
- `/ops/automation-governance`
- `/ops/automation-economics`

## Key trust points to call out
- No auto-activation.
- Explicit role-gating.
- Org-scoped data isolation.
- Deterministic blockers and state transitions.
