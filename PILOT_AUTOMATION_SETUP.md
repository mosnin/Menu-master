# Pilot Automation Setup Guide

## Pilot objective
Reach first value safely for one office/team before broad rollout.

## Step-by-step
1. Open `/ops/automation-library` and review package compatibility.
2. Import package as `draft_only`.
3. Open `/ops/automation-setup`.
4. Start onboarding session.
5. Resolve readiness blockers (entitlements, owner, reviewer, simulation, release review).
6. Validate environment from setup dashboard.
7. Activate pilot for one scoped team/office.
8. Track first-value milestones and adoption health.
9. Expand using staged rollout guidance only after healthy pilot signals.

## Exit criteria for pilot expansion
- Readiness state not blocked.
- At least one safe automated run.
- Measured time saved > 0.
- Override burden acceptable.
- No unresolved critical governance conflicts.
